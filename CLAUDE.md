# CLAUDE.md

Frontend-only chat application, built as a senior frontend take-home assessment.

The product brief below is the source of truth for scope and engineering principles. Folder
responsibilities and import rules are in `README.md`, and ESLint enforces the import rules.

@docs/project-context.md

## Commands

Use the Node version in `.nvmrc` (`nvm use`).

- `npm run dev`: start the development server
- `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run test:run`: validation
- `npm run build`: production build

## Git

Do not add a `Co-Authored-By` trailer or any Claude attribution to commits.
